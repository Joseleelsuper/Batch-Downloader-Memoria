% Abstract en castellano
\renewcommand*\abstractname{Resumen}
\begin{abstract}
La instalación inicial de un equipo obliga habitualmente a localizar y descargar cada aplicación desde una página distinta. Este Trabajo de Fin de Grado presenta \emph{Batch Downloader}, una plataforma web que centraliza un catálogo de software y permite seleccionar varias aplicaciones para obtener sus instaladores oficiales agrupados en un único archivo ZIP.

La plataforma no mantiene ejecutables de forma permanente. Cada solicitud crea un trabajo asíncrono que resuelve y valida fuentes externas, descarga temporalmente los archivos y prepara un ZIP que Core entrega mediante streaming y limpia según el estado de guardado y la actividad. El scraper y la búsqueda semántica constituyen dos partes centrales del proyecto. El sistema admite descargas anónimas, bundles oficiales y personales, acceso de usuarios mediante enlaces de un solo uso por correo y una interfaz en español e inglés.

La búsqueda ofrece modos literal y semántico. El servicio semántico usa un modelo local aprovisionado en la imagen o en el volumen persistente, sin descargar pesos dinámicamente; PostgreSQL con pgvector mantiene una proyección reconstruible, mientras MySQL conserva la autoridad sobre filtros, estados, facetas y paginación. Ante un índice incompleto, una consulta no elegible o un fallo, la petición completa se degrada a modo literal. Esta ampliación no introduce recomendaciones generativas ni creación automática de bundles.

La arquitectura utiliza Vite y TypeScript en el cliente, Java 26 y Spring Boot en el servidor, MySQL para los datos transaccionales, PostgreSQL con pgvector para la proyección semántica, RabbitMQ para el procesamiento asíncrono, Playwright para la resolución dinámica de páginas y contenedores Docker. La evaluación relaciona requisitos, riesgos y pruebas en dos cortes identificados de Git; los resultados no ejecutados se distinguen de los verificados.
\end{abstract}

\end{abstract}

% Abstract en inglés
\renewcommand*\abstractname{Abstract}
\begin{abstract}
Setting up a computer usually requires locating and downloading every application from a different website. This Bachelor's Degree Final Project presents \emph{Batch Downloader}, a web platform that provides a centralized software catalogue and allows users to select several applications and obtain their official installers grouped into a single ZIP archive.

The platform does not store executable files permanently. Each request creates an asynchronous job that resolves and validates external sources, temporarily downloads the files, and prepares a ZIP archive. Core streams the archive to the user and cleans up storage according to save and activity state. Source scraping and semantic search are both central to the project. The system supports anonymous downloads, official and user-owned bundles, single-use email links for user sign-in, and a Spanish and English interface.

Search supports lexical and semantic modes. A locally provisioned embedding model runs without dynamic weight downloads; PostgreSQL with pgvector stores a rebuildable projection, while MySQL remains authoritative for filters, status, facets, and pagination. An incomplete or unavailable semantic index, an ineligible query, or a service failure causes the entire request to fall back to lexical search. This extension does not add generative recommendations or automatic bundle creation.

The architecture uses Vite and TypeScript for the client, Java 26 and Spring Boot for the server, MySQL for transactional data, PostgreSQL with pgvector for the semantic projection, RabbitMQ for asynchronous processing, Playwright for dynamic page resolution, and Docker containers. The evaluation links requirements, risks, and tests across two identified Git revisions and distinguishes executed results from unverified claims.
\end{abstract}

\begin{abstract}

\end{abstract}
